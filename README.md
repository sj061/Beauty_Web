# Beauty_Web

내가 가진 화장품(기초/색조)을 카테고리별로 관리하는 웹앱.

## 보기 페이지

- `web/template.html` — 화면 틀. `scripts/build_page.py`가 data를 넣어 `web/index.html`을 만든다.
- 데이터를 고치면 `python3 scripts/build_page.py`로 다시 만들고 같은 Artifact 링크에 다시 올린다.
  링크: https://claude.ai/artifact/9YTQ1Gn8SGXzYEbDUX8DqZ

## 데이터

사용자가 목록을 보낼 때 형식 (한 줄에 제품 하나, 같은 제품이 여러 개면 여러 줄):

```
제품명+호수 / 개봉일(또는 미개봉, 개봉일을 모르면 사용중) / 개봉 후 사용기한 / 유통기한 / 가격 / 구매처 / 톤(색조만)
```

- `data/categories.json` — 카테고리 목록. `parents`는 소분류를 묶는 상위 이름(예: 마스크팩 → 보습/진정/기능성). `대분류(skincare/makeup/tools/etc) → 소분류 id → 한글 이름`
- `data/my-cosmetics.json` — 내가 가진 화장품. 카테고리와 같은 구조로, 소분류 id 아래에 제품 배열을 둔다.

제품 항목 형식:

```json
{
  "makeup": {
    "cushion": [
      {
        "name": "에스쁘아 프로테일러 쿠션 21호",
        "status": "in-use",
        "openedAt": "2026-10-03",
        "paoMonths": 12,
        "expiresAt": "2028-05-01",
        "useBy": "2027-10-03",
        "price": 32000,
        "store": "올리브영"
      }
    ]
  }
}
```

| 필드 | 뜻 | 비고 |
| --- | --- | --- |
| `name` | 제품명 (브랜드·호수 포함) | 필수 |
| `status` | `in-use`(사용중) / `unopened`(미개봉) / `used-up`(다 씀) | 모르면 `null` |
| `usedUpAt` | 다 쓴 날 `YYYY-MM-DD` | `used-up`일 때만 |
| `openedAt` | 개봉일 `YYYY-MM-DD` | 미개봉이거나 개봉일을 모르면 `null` |
| `paoMonths` | 개봉 후 사용기한 (개월) | 용기의 `12M` 표시 → `12`. `useBy` 계산용이며 화면에는 표시하지 않는다 |
| `expiresAt` | 유통기한 `YYYY-MM-DD` | |
| `useBy` | 실제 사용 기한 `YYYY-MM-DD` | 자동 계산: `openedAt + paoMonths`와 `expiresAt` 중 빠른 날짜. 미개봉이거나 개봉일을 모르면 `expiresAt` |
| `price` | 최저가 (원) | 실제 구매가가 아니라 사용자가 알아본 최저가 |
| `store` | 구매처 | |
| `memo` | 메모 (예: `소용량`) | 선택. 필요한 항목에만 둔다 |
| `tone` | 톤 목록 (예: `["코랄"]`, `["코랄", "핑크"]`) | 색조 제품만. 톤이 여러 개면 모두 넣는다. 모르면 `null` |

사용중인데 개봉일을 모르면 기록한 날을 개봉일로 보고 `openedAtAssumed: true`를 붙인다.

다 쓴 제품은 지우지 않고 `status: "used-up"`, `usedUpAt`을 넣어 기록으로 남긴다. 화면에서는 기본으로 숨기고 개수에서도 뺀다.

유통기한·개봉 후 사용기한이 둘 다 없는 제품은 일부러 비워둔 것이다(기한 전에 다 쓰는 제품, 하이라이터처럼 기한이 의미 없는 제품). 채우라고 묻지 않는다.

톤이 의미 없는 제품(아이브로우, 마스카라 등)은 톤을 비워둔다.

샘플은 해당 카테고리에 넣고 `sample: true`를 붙인다. 본품과 이름이 같으면 같은 제품으로 묶어 센다. 화면에서는 칸 맨 아래에 두고 "샘플" 필터로 모아 본다.

마스크팩은 용도별(보습/진정/기능성)로 나누고, 개봉일·개봉 후 사용기한 없이 미개봉으로 기록한다.

화면에는 개봉일을 표시하지 않는다. 미개봉 제품은 유통기한만, 사용중 제품은 유통기한과 사용 기한을 둘 다 보여준다.

`name` 외에는 모르면 `null`로 둔다. 같은 제품을 여러 개 가지고 있으면 항목을 개수만큼 넣는다.
제품마다 개봉일·유통기한이 다르기 때문이고, 개수는 같은 `name`의 항목 수로 센다.
개봉일·유통기한을 월까지만 알면 그 달 1일로 적는다. 연도가 두 자리(`29.01.13`)면 20XX년으로 본다.

목록을 정리할 때 제품명이 조금이라도 비슷한 항목(예: "롬앤 틴트 06" / "롬앤 쥬시래스팅 틴트 06")은
같은 제품인지 임의로 판단하지 말고 반드시 사용자에게 확인한 뒤 이름을 통일한다.
